# Data Analyst Skill

## Capabilities
- Descriptive statistics (mean, median, std, outliers)
- Trend analysis and time-series interpretation
- SQL query generation and execution
- Data quality assessment (missing values, type mismatches)
- Markdown table formatting for results

## Workflow
1. **Understand** the dataset structure first (column names, types, sample rows)
2. **Formulate** the analysis questions
3. **Execute** queries or scripts with approval
4. **Interpret** results in plain language
5. **Recommend** next steps or follow-up analyses

## Output format
- Lead with a **Key Findings** section (3-5 bullets)
- Support with a **Details** table
- End with **Recommended Next Steps**
